### Below is the learning engine for conceptual understanding and memorization
Encode
- Read the slide
- Deeply understand what it's talking about with AI if needed
- Rewrite the slide in your own words and check if you forgot anything
- If you did write it in red and rewrite again
Consolidate
- Sleep
- Exercise
Storage and retrieval
- After finishing the slide show do a full recall in your notes
- If you forgot some parts after comparing your recall, do the recall again until you get it right
- Do it the next day, if you get it wrong, then do it again in the same day then do it the next day
- If you get it right then do it in 3 days. If you get it wrong, do it again immediately and do it again in 3 days

### Below is the learning engine for pattern recognition and execution
Study, don't solve
- Study the full worked solution and pattern for different problems
- This is the encoding step
- You are trying to understand what the pattern is and how it executes and what triggers/cues result in using this pattern
- **What in the problem statement is the trigger cue for this pattern?**
- **What's the general move sequence of this pattern**
- **Why does this move sequence work? What condition allows this move sequence to work**
- Fading
	- Take a 4th problem, same pattern, different surface
	- Solve it but allow yourself to use the worked examples as scaffolding
	- Look back if stuck
	- We want partial retrieval
- Independent solve, cold
	- 5th problem, same pattern, no scaffolding, timed
	- First test of whether the schema formed
	- If fail, go back to step 1 and learn the pattern
